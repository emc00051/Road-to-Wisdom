This project was created by myself and a friend for our band service fraternity, Kappa Kappa Psi. Using no game engine, I worked on all of the code and my friend worked on the artwork to make a 2D adventure game. Game was created in early 2025. There are minor bugs and things to tweak, but we made the game so both of us could get more expereince in the minute details of code and artwork, so they haven't been worked on in a long time.
